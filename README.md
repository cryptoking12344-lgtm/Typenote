# Typenote

A little typewriter for your notes, for Android.

- Textured paper under a real platen roller, with chrome knobs, a scale bar and a red carriage marker that follows your typing
- Uneven ribbon ink (Fresh, Faded, Smudged, Crisp), adjustable type size and margins
- Backspace either strikes letters through or erases them cleanly
- Synthesised key strikes, end-of-line bell and carriage return, with haptics on every key
- Desk lamp for night writing: warmth, brightness and beam width (long-press the roller to toggle)
- Notes saved on the device automatically, plus a Save button; search, monthly groups, Recently deleted (30 days), share as text
- Up to 3,000 characters per sheet

## Build

Every push to `main` builds a signed APK with GitHub Actions. Download it from the
**Releases** page (or the run's artifacts) and install it on your phone.

The typewriter font is [Special Elite](https://fonts.google.com/specimen/Special+Elite) (Apache 2.0),
fetched during the build.
